AI Troubleshooting Assistant

Add an API key for whichever AI provider(s) the company has access to. Technicians pick from whichever providers have a key set here — no personal key needed on their end anymore.

These keys are stored in Firestore and used directly from each technician's browser when they chat with the assistant — this gets keys out of the app's source code, but a technician inspecting network traffic while using the assistant could still read whichever key their chosen provider is using. Use a key scoped to this app only (not a personal/shared account key), and keep an eye on usage from each provider's own dashboard.
